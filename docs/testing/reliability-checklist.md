# Reliability checklist

## v0.8.6 — Whitelist-First Statistics UI

- Главный экран: карточка статистики показывает whitelist summary.
- Экран «Статистика»: без полной technical check statistics в основном потоке.
- Диагностика: rebuild и агрегаты проверок доступны.
- Перезапуск и обновление с v0.8.5: данные whitelist availability сохранены.

# v0.8.3 — Statistics Reliability & Diagnostics

## Проверка после перезапуска

- Выполнить успешную проверку.
- Закрыть приложение.
- Открыть приложение.
- Проверить главный экран.
- Проверить экран статистики.
- Проверить diagnostics.

## Проверка после обновления

- Установить v0.8.2.
- Выполнить несколько проверок.
- Обновиться до v0.8.3.
- Проверить, что история и статистика не потерялись.
- Проверить rebuild.

## Проверка без сети

- Отключить сеть.
- Выполнить проверку.
- Проверить сохранение ошибочного результата.
- Проверить статистику ошибок.
- Проверить отсутствие падений.

## Проверка ошибок endpoint'ов

- Использовать недоступный endpoint.
- Использовать endpoint с timeout.
- Использовать endpoint с DNS error.
- Проверить CheckTargetResult.
- Проверить статистику.
- Проверить UI.

## Проверка cleanup

- Создать много check runs.
- Запустить cleanup.
- Проверить, что свежие записи остались.
- Проверить, что target results не стали orphan records.
- Проверить daily statistics.
- Проверить diagnostics.

## Проверка rebuild

- Выполнить несколько проверок.
- Запустить rebuild статистики.
- Сравнить summary до и после.
- Проверить экран статистики.
- Проверить diagnostics warnings.

## Проверка плохих данных

- Проверить отсутствие null в UI.
- Проверить отсутствие NaN в UI.
- Проверить отсутствие Infinity в UI.
- Проверить fallback для неизвестного operator.
- Проверить fallback для неизвестного routeKind.

## Проверка приватности

- Проверить логи.
- Проверить diagnostics.
- Проверить экран статистики.
- Убедиться, что нет токенов, IMSI, IMEI, номера телефона, точных координат и секретов.
