# Telegram bot buttons and distributed reports

## Цель

Добавить в будущую распределённую систему управляемые кнопки Telegram-бота без превращения Android-приложения в удалённо управляемый бот-клиент.

Пользователь должен явно выбирать:

- регион;
- отправлять или не отправлять агрегированные данные;
- разрешать или запрещать запрос теста из Telegram;
- отправлять данные только через свой или доверенный relay, без `BOT_TOKEN` в Android.

## Важное ограничение мгновенного теста

Telegram-кнопка сама по себе не может мгновенно разбудить произвольное Android-приложение.

Без FCM, foreground service или фонового long polling реальный путь такой:

```text
Пользователь нажал кнопку в Telegram
    -> Worker сохранил pending command
    -> Android забрал команду при следующей ручной/фоновой синхронизации
    -> Android выполнил проверку
    -> Android отправил результат через Worker
```

Поэтому опция должна называться осторожно:

```text
Разрешить тест по запросу из бота
```

А не:

```text
Мгновенно проверить телефон
```

## Кнопки MVP

Inline keyboard для пользователя:

```text
[Регион]
[Отправка данных: вкл/выкл]
[Тест по запросу: разрешён/запрещён]
[Запросить проверку]
[Мои настройки]
```

## Регион

Регион задаётся пользователем вручную. Не определять регион по геолокации в MVP.

Минимальная модель:

```json
{
  "region": "moscow",
  "regionLabel": "Москва",
  "updatedAt": 1710000000000
}
```

## Отправка данных

Разрешены только агрегированные отчёты без секретов:

- версия приложения;
- регион пользователя;
- timestamp проверки;
- confirmed whitelist state;
- количество доступных FOREIGN/LOCAL целей;
- список target host + status + latency bucket.

Не отправлять:

- Relay Secret;
- `BOT_TOKEN`;
- полный URL Worker;
- пользовательские комментарии без отдельного согласия;
- точный IP;
- точную геолокацию.

## Команды Worker

Предлагаемые endpoints:

```text
POST /api/device/report
POST /api/device/pullCommands
POST /api/device/ackCommand
POST /tg/webhook
```

Все Android endpoints должны требовать device secret или relay secret пользователя.

## Антиабьюз

Для кнопки запроса теста:

- cooldown на устройство;
- максимум команд в очереди;
- expiry pending command;
- пользовательский opt-in в Android;
- Telegram chat allowlist;
- audit log без секретов.

## Что не делать

- Не реализовывать `getUpdates`/long polling в фоне Android.
- Не принимать команды от любого Telegram-чата.
- Не отправлять прямые запросы на `api.telegram.org` из Android.
- Не хранить `BOT_TOKEN` в Android.
- Не обещать мгновенный тест без отдельного push-канала.
