# v0.8.11 — Selectable statistics periods

## Цель

Дать пользователю выбрать не только масштаб графика БС, но и конкретный день, неделю, месяц или год.

## Изменено

- В графике БС остались масштабы «День», «Неделя», «Месяц», «Год».
- Для выбранного масштаба показывается конкретный период:
  - день — выбранная дата по часам;
  - неделя — календарная неделя с понедельника по воскресенье;
  - месяц — полный выбранный календарный месяц;
  - год — полный выбранный календарный год по месяцам.
- Добавлены стрелки перехода к предыдущему/следующему периоду.
- Добавлена кнопка «Выбрать» с системным выбором даты.
- Добавлена кнопка «Текущий» для возврата к текущему периоду.
