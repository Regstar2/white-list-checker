# v0.8.9 — Statistics navigation polish

## Цель

Сократить статистику БС на главном экране до одного входа через быстрые действия и сделать экран статистики более управляемым.

## Изменено

- Убрана отдельная домашняя плашка «Статистика БС».
- В быстрые действия добавлена кнопка «Статистика» с переходом к графику БС.
- На экране статистики теперь один бинарный график, а период выбирается кнопками:
  - день;
  - неделя;
  - месяц;
  - год.
- Системная кнопка/жест назад на внутренних экранах возвращает на главный экран приложения.
