`v0.10.2 — Public Telegram Bot Beta`

## Контекст

Access model и privacy/abuse protection готовы. Теперь можно включить публичную beta общего Telegram-бота.

## Проблема

Public mode должен быть включён аккуратно: понятный /start, безопасные команды, rate limit, feedback и disclaimer.

## Цель версии

1. Включить public mode через config.
2. Добавить публичные команды и кнопки.
3. Показать beta disclaimer.
4. Сохранить admin-only команды закрытыми.
5. Сохранить privacy filters/rate limits.
6. Добавить feedback route.
7. Не делать рассылки и подписки.

## Архитектурный принцип

Public mode должен управляться config/env. Public command handlers обязаны проходить через BotAccessPolicy, PrivacyFilter и RateLimitPolicy.

## Требования к реализации

- `/start` объясняет beta, агрегированность данных, ограничения точности, privacy и основные кнопки.
- `/help` показывает только доступные public commands.
- `/status` показывает общий status/freshness без internal diagnostics.
- `/region`, `/operator`, `/target` возвращают public-safe агрегаты.
- `/feedback` принимает короткий feedback с лимитом длины.
- Public mode off закрывает доступ public users, но admin остаётся.

## Приватность и безопасность

Запрещено сохранять, показывать, отправлять или логировать:

- номер телефона;
- IMEI;
- IMSI;
- точные координаты;
- токены;
- bot token;
- shared secret;
- authorization headers;
- приватные URL и query-параметры с секретами;
- raw reports там, где пользователь должен видеть только агрегаты.

Если поле сомнительное — не включай его в публичный/серверный контракт без явного обоснования.
