# v0.8.2 — Statistics UI

## Цель

Добавить интерфейс для просмотра локальной статистики проверок.

## Входит в версию

- Короткая сводка статистики на главном экране.
- Отдельный экран «Статистика».
- Отображение общей статистики.
- Отображение статистики по endpoint/target.
- Отображение статистики по routeKind.
- Отображение статистики по networkType/operator.
- Отображение статистики по дням.
- Loading, empty и error-состояния.
- Отображение устаревших данных.
- Пользовательские строки в ресурсах.

## Не входит в версию

- Новая запись статистики.
- Переписывание Local Statistics Writer.
- Сложные графики.
- Экспорт.
- Worker.
- Telegram Bot.
- Multi-device reports.
- Отправка данных наружу.

## Архитектурные ограничения

- Не считать статистику в UI.
- Использовать StatisticsRepository из v0.8.1.
- Не смешивать UI, domain и data.
- Не показывать чувствительные данные.
- Не добавлять функции будущих версий.
- Не делать большой рефакторинг главного экрана.

## Ручное тестирование

- Открыть главный экран без статистики.
- Выполнить проверку и увидеть краткую сводку.
- Открыть экран статистики.
- Проверить общую статистику, endpoints, routeKind, network/operator, daily statistics.
- Проверить empty, error (если возможно) и stale state.
- Проверить перезапуск приложения и обновление с v0.8.1.
