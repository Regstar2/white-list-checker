# v0.8.0 — Check Result Persistence Foundation

## Цель

Добавить локальное сохранение результатов завершённых проверок как основу для будущей статистики.

## Входит в версию

- Модель CheckRun.
- Модель CheckTargetResult.
- Локальное сохранение завершённых проверок (Room).
- Repository для истории проверок.
- Cleanup старых записей.
- Минимальные тесты persistence/domain-логики.

## Не входит в версию

- Экран статистики.
- Агрегированная статистика.
- Графики.
- Worker (только запись истории при фоновой проверке).
- Telegram Bot.
- Multi-device reports.
- Отправка данных наружу.

## Архитектурные ограничения

- Не смешивать UI, domain и data.
- Не менять check algorithm без необходимости.
- Не сохранять чувствительные данные.
- Не добавлять функции будущих версий.

## Ручное тестирование

- Выполнить успешную проверку и убедиться, что check run сохраняется.
- Выполнить ошибочную проверку и убедиться, что ошибка сохраняется.
- Выполнить несколько проверок подряд — записи не перетирают друг друга.
- Перезапустить приложение — история не пропадает; главный экран работает как в v0.7.2.

## Критерии готовности

- Завершённая проверка сохраняется локально.
- Target results связаны с check run.
- История не растёт бесконечно.
- Last check state не сломан.
- Проект собирается.
