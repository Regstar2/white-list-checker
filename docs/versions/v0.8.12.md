# v0.8.12 — Home screen UX polish

## Цель

Переработать главный экран без изменения алгоритмов проверки, сетевой логики, хранилища и фоновых задач.

## Изменено

- Верхняя часть главного экрана стала компактнее.
- Основная кнопка проверки сохраняет существующий обработчик и показывает состояние выполнения внутри кнопки.
- Карточка последнего результата стала центральным элементом экрана.
- В карточке убраны повторы «последний результат / последняя проверка / статус / время».
- Локальные и внешние проверки показываются двумя компактными строками с исходными счётчиками доступности.
- Маршрут проверки отображается понятным текстом без сырого `Mobile`.
- Добавлена кнопка «Подробнее» с переходом в существующую диагностику.
- Быстрые действия стали компактнее и получили иконки.
- Пятая плитка «Диагностика» занимает всю ширину в двухколоночной сетке.
- Новые пользовательские строки вынесены в ресурсы.

## Что не менялось

- Алгоритм определения белых списков.
- Сетевые запросы и выбор cellular `Network`.
- Список проверяемых сайтов.
- Room/DataStore и формат сохранённых данных.
- WorkManager-задачи.
- Telegram-интеграция.
