# v0.10.4 — Statistics UI, Diagnostics UI, Localization & Local Export

## Цель

Переработать экран «Статистика» в компактный `whitelist-first` dashboard по Variant A, обновить диагностический UI, добавить безопасный локальный export статистики и исправить переключение языка без изменений network/classifier/DNS-логики.

## Версия

```text
versionName: 0.10.4
versionCode: 25
```

## Что изменено

- Добавлен главный hero-блок текущего бинарного состояния: `Похоже на включённые белые списки`, `Белые списки не обнаружены` или `Нет бинарного статуса`.
- Freshness переведён в компактную строку вида `Обновлено ... • Последняя проверка ...`.
- Добавлены компактные метрики `Бинарных сэмплов` и `Последняя проверка`.
- Блок истории отделён заголовком, а график оставлен на существующем `BinaryTimelineChart`.
- Переключатель периода `День / Неделя / Месяц / Год` стал компактной строкой `FilterChip`.
- Навигация по датам стала одной строкой со стрелками и центральной датой; переход в будущее запрещён.
- Быстрый переход `К текущему` показывается только для прошлого периода.
- Большой технический dashboard убран с основного экрана статистики.
- Diagnostics остаётся доступным через компактную navigation-card `Технические данные проверок`.
- Добавлена кнопка `Экспортировать статистику` в основном содержимом экрана.
- Экран «Диагностика» стал компактным Material 3 экраном с главным результатом, сводкой, раскрываемыми группами сайтов, мониторингом состояния и раскрываемой технической статистикой.
- Выбор языка `Русский / English / System` теперь меняет Compose UI через локализованный context.
- `README.md` и `README_EN.md` синхронизированы и дополнены скриншотами из `docs/assets/screenshots/`.
- Исправлен запуск приложения после подмены локализованного `LocalContext`: `ActivityResultRegistryOwner` явно сохраняется в composition locals.

## Экспорт

- Добавлен bottom sheet `Экспорт статистики` с выбором формата `CSV`, `JSON`, `TXT`.
- Добавлен выбор scope:
  - текущий выбранный период;
  - вся сохранённая локальная история, фактически доступная dashboard.
- Для сохранения используется Android Storage Access Framework через `ActivityResultContracts.CreateDocument`.
- Storage permissions `READ_EXTERNAL_STORAGE`, `WRITE_EXTERNAL_STORAGE`, `MANAGE_EXTERNAL_STORAGE` не добавлялись.
- `StatisticsExportBuilder` является чистым Kotlin-классом и не зависит от Compose, Activity, Context, Uri или ContentResolver.
- Запись в `Uri` вынесена в отдельную platform-boundary функцию `StatisticsExportFileWriter`.

## CSV

- Одна строка соответствует одному timeline sample.
- Колонки: `checked_at_iso`, `checked_at_epoch_ms`, `whitelist_state`, `binary_state`, `period`.
- Используется UTF-8 с BOM для совместимости с Excel-подобными приложениями.
- Реализовано CSV escaping для запятых, кавычек, CR/LF и кириллицы.

## JSON

- Добавлен `schemaVersion: 1`.
- Экспортируются безопасные агрегаты: summary, freshness, technicalSummary, samples и buckets выбранного периода.
- Для `AllHistory` samples включают всю локально загруженную историю, а buckets остаются пустыми, потому что весь диапазон не соответствует одному отображаемому графику.
- JSON формируется через `org.json`, не ручной конкатенацией.

## TXT

- Добавлен человекочитаемый отчёт с периодом, текущим состоянием, последним бинарным статусом, процентом БС за период, количеством бинарных сэмплов, последней проверкой и историей samples.

## Privacy

Экспорт полностью локальный:

- не отправляется в Cloudflare Worker;
- не отправляется в Telegram;
- не отправляется в public service;
- не отправляется на сервер или в analytics.

В export не включаются:

- `BOT_TOKEN`, `PUBLIC_BOT_TOKEN`, Relay Secret;
- Telegram `chat_id`;
- device token, `DEVICE_TOKEN_PEPPER`, `ADMIN_API_SECRET`, webhook secret, auth headers;
- installation token;
- координаты, IMEI, IMSI, номер телефона, SIM serial;
- Wi-Fi SSID/BSSID;
- raw target URLs, stack traces и внутренние ID БД.

## Не входит в версию

- изменение classifier;
- изменение DNS logic;
- изменение VPN / Private DNS logic;
- изменение WorkManager;
- изменение Telegram;
- изменение Cloudflare Worker;
- изменение public service;
- изменение Room schema;
- изменение D1;
- cloud export.

## Manual test checklist

1. Открыть экран «Статистика».
2. Проверить, что главный статус виден сразу.
3. Проверить процент `БС были за период`.
4. Проверить количество бинарных samples и последнюю проверку.
5. Переключить `День`, `Неделя`, `Месяц`, `Год`.
6. Перейти стрелкой назад и вперёд, убедиться, что в будущее уйти нельзя.
7. Нажать центральную дату и выбрать другой период.
8. Проверить появление `К текущему` для прошлого периода.
9. Проверить график и легенду.
10. Открыть `Технические данные проверок` и убедиться, что открывается Diagnostics.
11. Экспортировать CSV/JSON/TXT для текущего периода.
12. Экспортировать CSV/JSON/TXT для всей сохранённой истории.
13. Закрыть системный dialog без сохранения и убедиться, что ошибка не показывается.
14. Проверить большой font scale, тёмную тему и экран около 360 dp.
