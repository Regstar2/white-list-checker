# v0.8.14 — Central public Telegram service MVP

## Цель

Добавить центральный Cloudflare-сервис с публичным Telegram-ботом, добровольной отправкой обезличенных reports и удалённой проверкой связанных устройств без поломки личного Telegram relay.

## Что добавлено

- Новый Worker в `cloudflare/public-service/`.
- D1 schema для installations, reports, Telegram users, link codes, links, commands, command results и cleanup.
- Public aggregate flow: `/status` и кнопка «Статус по данным пользователей».
- PublicStatusAggregator с окнами свежести, minimum sample, consensus threshold и правилом «один последний report на installation».
- Android `PublicServiceClient`, registration use case, secure device token storage и settings repository.
- Отдельная Room-очередь `pending_public_reports`.
- Отдельный экран «Общий сервис» с public sharing, remote checks, link code и удалением серверных данных.
- Foreground service polling `service-sync` для remote command `CHECK_NOW`.
- Trigger `REMOTE_TELEGRAM` в локальной истории.

## Что не менялось

- Алгоритм `WhitelistStateClassifier`.
- Список проверяемых сайтов.
- Cellular routing через `Network.openConnection(...)`.
- Личный Telegram relay пользователя.
- Очередь личных Telegram-сообщений.
- WorkManager intervals и notification policies.
- Локальная история проверок, кроме добавления нового trigger.

## Privacy

`shareReports=false` и `allowRemoteChecks=false` по умолчанию.

Android хранит device token через Android Keystore-backed encryption. Worker хранит только token hash с server-side pepper.

Публичная статистика не раскрывает `installationId`, `chatId`, токены, Relay Secret, `BOT_TOKEN`, IP или отдельные raw reports устройств.

## Ограничения MVP

- Production Worker deploy и webhook setup выполняются вручную.
- Remote check работает только при active foreground service.
- HTTP polling добавляет задержку.
- Android может остановить foreground service.
- Client reports нельзя считать абсолютно доверенными без device attestation.
- WebSocket и Durable Objects не входят в MVP.

## Проверки

- Worker: `npm run typecheck`, `npm run lint`, `npm test`, `npm run build`.
