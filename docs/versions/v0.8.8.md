# v0.8.8 — Binary whitelist timeline

## Цель

Перевести статистику с доступности отдельных целей на главный вопрос приложения:

```text
в этот момент времени были признаки белых списков или нет
```

## Входит в версию

- Добавлена отдельная Room-таблица `whitelist_timeline_samples`.
- Каждый сохранённый check run теперь пишет лёгкий timeline-сэмпл:
  - время проверки;
  - исходный `WhitelistState`;
  - бинарный статус `ON` / `OFF` / `UNKNOWN`.
- Существующая история `check_runs` мигрируется в новую timeline-таблицу при переходе базы с версии 5 на 6.
- Экран «Статистика» теперь показывает бинарный график:
  - сегодня по часам;
  - день;
  - неделя;
  - месяц;
  - год.
- В bucket интервала статус `ON` побеждает `OFF`: если за интервал была хотя бы одна проверка `WHITELIST_ON`, интервал считается «БС были».
- Состояния `NO_MOBILE_INTERNET`, `MOBILE_DNS_FAILURE`, `PARTIAL_PROBLEM`, `CELLULAR_NETWORK_UNAVAILABLE`, `UNKNOWN` не превращаются в `OFF`; они отображаются как отсутствие бинарного статуса.
- С главного экрана убраны плашки:
  - «Маршрут проверки»;
  - «Краткий статус».
- Домашняя статистическая карточка переработана под бинарную статистику БС.

## VPN/DNS

Приложение запрашивает cellular `Network` и выполняет HTTP(S)-проверки через `network.openConnection(...)`.

Это помогает проверять мобильную сеть даже при активном Wi-Fi, но не является гарантированным обходом любого VPN или системного DNS:

- если VPN разрешает bypass, Android может дать приложению отправить трафик через cellular `Network`;
- если VPN не разрешает bypass, обычное приложение не может гарантированно обойти VPN;
- Private DNS, APN, прошивка, корпоративный профиль или VPN могут влиять на DNS;
- если DNS массово ломается через cellular `Network`, это классифицируется как `MOBILE_DNS_FAILURE`, а не как «БС включены».

Подробно: [network-routing-notes.md](../network-routing-notes.md)

## Не входит в версию

- Минутная детализация с постоянным polling.
- FCM/push-команды из Telegram.
- Foreground service.
- VPN/proxy service.
- Прямой Telegram Bot API из Android.
