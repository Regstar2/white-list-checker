# v0.7.2 — Last Check Stale State Fix

## Цель

Исправить отображение последней проверки на главном экране, если проверка была давно.

## Входит в версию

- Отображение старой последней проверки.
- Явное stale/outdated-состояние.
- Отображение возраста последней проверки.
- Корректное отображение старой ошибки последней проверки.
- Сохранение последнего результата проверки в DataStore.

## Не входит в версию

- История проверок.
- Статистика.
- Worker.
- Telegram Bot.
- Multi-device reports.

## Архитектурные ограничения

- Не вычислять stale-состояние прямо в UI.
- Не смешивать UI, domain и data.
- Не добавлять функции будущих версий.
- Не менять routing/proxy/checking logic без необходимости.

## Ручное тестирование

- Проверка никогда не выполнялась.
- Последняя проверка свежая.
- Последняя проверка старая.
- Последняя проверка свежая и ошибочная.
- Последняя проверка старая и ошибочная.
- Проверка выполняется сейчас.
- Перезапуск приложения после старой проверки.

## Критерии готовности

- Главный экран не скрывает старую последнюю проверку.
- Старые данные помечаются как устаревшие.
- Отсутствие проверки отличается от устаревшей проверки.
- Старая ошибка последней проверки тоже отображается.
- Новые строки вынесены в ресурсы.
- Проект собирается.
