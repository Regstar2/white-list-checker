# v0.8.6 — Whitelist-First Statistics UI

## Цель

Сделать экран статистики ориентированным на белые списки и доступность целей, а техническую статистику проверок сократить или вынести в логи/диагностику.

## Входит в версию

- Перестройка экрана статистики вокруг whitelist availability.
- Удаление большой технической статистики проверок из основного Statistics UI.
- Минимальный technical summary только для актуальности данных.
- Перенос подробных check statistics в diagnostics/collapsed technical block.
- Компактная карточка статистики на главном экране.
- Блок текущего состояния целей.
- Блок последних изменений whitelist availability.
- Улучшение графиков доступности и включений/выключений.
- Безопасные display labels для целей/endpoints.
- Обновление пользовательских строк.
- Обновление ручного test plan.

## Не входит в версию

- Worker, Telegram Bot, multi-device reports, экспорт, сложные фильтры.
- Удаление CheckRun/CheckTargetResult.
- Полная переработка архитектуры статистики.
