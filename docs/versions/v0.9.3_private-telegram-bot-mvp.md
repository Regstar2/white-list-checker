## Контекст

Worker уже агрегирует отчёты и имеет private read endpoints. Теперь нужен приватный Telegram-интерфейс для admin.

## Проблема

Агрегаты есть, но смотреть их неудобно. Нужен закрытый bot MVP без публичного доступа.

## Цель версии

1. Добавить Telegram webhook.
2. Проверять webhook secret/admin chat id.
3. Добавить admin-only команды.
4. Показывать агрегированную статистику.
5. Не показывать raw reports.
6. Не открывать public access.

## Архитектурный принцип

Схема: `Telegram webhook -> TelegramSecurityVerifier -> BotCommandRouter -> BotQueryService -> AggregationRepository -> BotMessageFormatter -> sendMessage`. Не дублировать aggregation logic в bot handler.

## Требования к реализации

- Webhook должен проверять secret token или безопасный аналог.
- Доступ только admin chat id.
- Non-admin получает короткий отказ без деталей.
- Команды должны отвечать коротко, top 5/top 10 для длинных списков.
- `/diagnostics` показывает counts/warnings без sensitive data.
- Bot token и secrets не логировать и не хранить в репозитории.

## Приватность и безопасность

Запрещено сохранять, показывать, отправлять или логировать:

- номер телефона;
- IMEI;
- IMSI;
- точные координаты;
- токены;
- bot token;
- shared secret;
- authorization headers;
- приватные URL и query-параметры с секретами;
- raw reports там, где пользователь должен видеть только агрегаты.

Если поле сомнительное — не включай его в публичный/серверный контракт без явного обоснования.
