# v0.8.7 — Stabilization, richer defaults and chart polish

## Цель

Довести текущий MVP до более нормального состояния без перехода к новой серверной архитектуре.

## Входит в версию

- Расширены встроенные FOREIGN/LOCAL цели до 8 + 8.
- Добавлена мягкая миграция новых built-in целей для пользователей, у которых старый набор не был вручную урезан.
- Исправлена запись `networkType` в истории: статистика теперь пишет проверяемую сеть `Mobile`, а не активную сеть телефона.
- На главном экране показан статус записи истории и агрегатов статистики.
- Домашняя карточка статистики показывает доступные цели как `N/M`.
- Дневная доступность целей отображается линейным графиком.
- В техническом блоке добавлен график успешности target-проверок по дням.
- Обновлена цветовая тема и базовый стиль карточек.
- Добавлена документация по ограничениям VPN/Private DNS.
- Добавлен проектный документ по кнопкам Telegram-бота и региональным opt-in настройкам.

## Не входит в версию

- Настоящий distributed backend.
- Публичный общий бот.
- FCM/push для мгновенных команд.
- Direct Telegram Bot API из Android.
- Обход VPN, если VPN не разрешает bypass на уровне Android.

## Ручная проверка

1. Открыть приложение.
2. Проверить, что главный экран выглядит аккуратнее и показывает маршрут проверки.
3. Открыть настройки проверки и проверить, что появилось больше встроенных FOREIGN/LOCAL целей.
4. Выполнить ручную проверку мобильной сети.
5. Проверить, что после проверки на главном экране появился статус записи статистики.
6. Открыть статистику и проверить дневный график доступности.
7. Раскрыть технический блок и проверить график успешности целей по дням, если данных достаточно.
