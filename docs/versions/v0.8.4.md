# v0.8.4 — Whitelist Availability Statistics

## Цель

Добавить локальную статистику появления и исчезновения доступности targets поверх истории проверок.

## Входит в версию

- События и агрегаты whitelist availability.
- Rebuild из истории.
- UI-блок и графики на экране «Статистика».

## Не входит в версию

- Worker, Telegram, multi-device, экспорт, отправка данных наружу.
