# v0.8.15 — fixed public service URL and area/operator selection

## Цель

Переработать экран «Общий сервис и Telegram-бот» после MVP центрального сервиса:

- убрать ручной ввод URL общего сервиса;
- добавить авто/ручной выбор региона и города;
- добавить авто/ручной выбор мобильного оператора;
- сохранить независимость личного Telegram relay.

## Android

- URL центрального сервиса берётся из `BuildConfig.PUBLIC_SERVICE_BASE_URL`.
- Старое DataStore-поле `public_service_base_url` больше не используется и очищается при сохранении настроек.
- Личный `Worker URL` на экране уведомлений остаётся пользовательским.
- Регион и город разделены: `regionCode` обязателен для sharing, `cityCode` необязателен.
- Автоопределение местоположения запускается только по нажатию пользователя.
- Используется `ACCESS_COARSE_LOCATION`, `LocationManager` и `Geocoder`.
- После автоопределения пользователь подтверждает результат или исправляет вручную.
- Координаты, точный адрес, улица и postal code не сохраняются и не отправляются.
- Оператор определяется по active/default data subscription через `TelephonyManager`.
- `networkOperator` MCC+MNC имеет приоритет над SIM operator.
- Ручной выбор оператора не перезаписывается автоматикой.
- `READ_PHONE_STATE` не добавлялся; номер телефона, IMEI, IMSI и SIM serial не читаются.

## Worker

- Public report contract расширен полями `cityCode`, `customCityName`, `areaSource`, `operatorSource`.
- Добавлены D1-колонки для города и источников area/operator.
- Добавлены public catalog endpoints:
  - `GET /api/v1/catalog/regions`
  - `GET /api/v1/catalog/regions/{regionCode}/cities`
  - `GET /api/v1/catalog/operators`
- Добавлен `MIN_UNIQUE_INSTALLATIONS_FOR_CITY` для более строгого порога городской статистики.

## Privacy

Публичный report не содержит:

- latitude / longitude;
- raw address;
- street;
- postal code;
- cell ID;
- IMSI;
- IMEI;
- phone number;
- SIM serial;
- Wi-Fi SSID / BSSID.

Городская статистика не должна показываться при малой выборке.

## Миграция

- Существующие `regionCode` и `operatorCode` сохраняются как ручной выбор.
- Новые пользователи получают `shareReports=false`, `allowRemoteChecks=false`.
- Автоматическое определение региона, города и оператора не включается без действия пользователя.
- Настройки личного Telegram relay не меняются.

## Ограничения

- Встроенный Android-каталог городов является MVP fallback, а не полной федеральной базой населённых пунктов.
- Реальный production URL должен соответствовать фактическому Cloudflare Worker deploy.
- Проверка remote command по-прежнему работает только пока активный foreground service присылает heartbeat.
