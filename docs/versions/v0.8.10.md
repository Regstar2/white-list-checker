# v0.8.10 — Natural statistics periods

## Цель

Заменить странные технические интервалы графика БС на привычные пользовательские периоды.

## Изменено

- Кнопки периода графика: «День», «Неделя», «Месяц», «Год».
- «День» отображается по часам текущего дня.
- «Неделя» отображается по дням за последние 7 дней.
- «Месяц» отображается по дням за последние 30 дней.
- «Год» отображается по месяцам за последние 12 месяцев.
