# v0.8.3 — Statistics Reliability & Diagnostics

## Цель

Повысить надёжность локальной истории и статистики, добавить диагностику согласованности данных и безопасный rebuild статистики.

## Входит в версию

- Диагностика истории проверок.
- Диагностика агрегированной статистики.
- Проверка согласованности CheckRun, CheckTargetResult и statistics aggregates.
- Укрепление rebuild статистики из истории.
- Проверка cleanup истории и статистики.
- Защита UI от null/NaN/Infinity и повреждённых данных.
- Обработка ошибок storage/statistics.
- Reliability checklist.
- Минимальные тесты rebuild, cleanup и consistency checks.

## Не входит в версию

- Новые метрики статистики сверх диагностики.
- Сложные графики.
- Экспорт.
- Worker.
- Telegram Bot.
- Multi-device reports.
- Отправка данных наружу.

## Архитектурные ограничения

- Не пересчитывать статистику в UI.
- Не выполнять rebuild на каждом запуске без причины.
- Не смешивать UI, domain и data.
- Не показывать и не логировать чувствительные данные.
