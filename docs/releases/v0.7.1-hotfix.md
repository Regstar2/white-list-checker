# WhiteListChecker v0.7.1 Hotfix

Hotfix для MVP-релиза `v0.7.0-mvp`.

## Исправлено

- Возвращено Android permission `CHANGE_NETWORK_STATE`.
- Исправлена ошибка при ручной проверке мобильной сети:

```text
was not granted either of these permissions:
android.permission.CHANGE_NETWORK_STATE,
android.permission.WRITE_SETTINGS
```

## Причина

WhiteListChecker явно запрашивает cellular network через `ConnectivityManager.requestNetwork()`, чтобы проверять мобильную сеть даже при активном Wi-Fi. Для этого требуется `CHANGE_NETWORK_STATE`.

## Что не изменилось

- `WRITE_SETTINGS` не добавлен.
- Telegram по-прежнему работает только через пользовательский Cloudflare Worker relay.
- `BOT_TOKEN` не хранится в Android.
- Уведомления отправляются только при подтверждённой смене статуса.

## Установка

Скачайте APK из [GitHub Releases](https://github.com/Regstar2/WhiteListChecker/releases/tag/v0.7.1-hotfix).

**Примечание:** debug APK для MVP-тестирования.
