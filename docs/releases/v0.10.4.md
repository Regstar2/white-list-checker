## О релизе

`v0.10.4` — beta/prerelease для Android-приложения WhiteListChecker. Версия обновляет экраны статистики и диагностики, добавляет локальный экспорт статистики, исправляет переключение языка приложения и обновляет публичный README со скриншотами.

Миграция пользовательских данных не требуется. Опубликованный APK собран из подписанного `release` variant.

## Главное

- Экран «Статистика» стал компактнее и получил локальный экспорт в `CSV`, `JSON` и `TXT`.
- Экран «Диагностика» показывает главный результат, сводку и проблемные сайты без длинного технического отчёта на первом уровне.
- Выбор `English` в настройках теперь реально переключает интерфейс приложения.
- README на русском и английском синхронизированы и дополнены скриншотами.
- Исправлен краш запуска, связанный с локализованным Compose `LocalContext`.

## Изменения

### Добавлено

- Локальный экспорт статистики через Android Storage Access Framework без storage permissions.
- Форматы экспорта `CSV`, `JSON` и `TXT` для выбранного периода или всей локально загруженной истории.
- Полноценный английский перевод основных экранов приложения.
- Раздел `Скриншоты` / `Screenshots` в README; изображения находятся в `docs/assets/screenshots/`.
- Полные release notes для `v0.10.4` на русском и английском.

### Изменено

- Экран «Статистика» переработан в `whitelist-first` dashboard с главным бинарным статусом, freshness-строкой, ключевыми метриками и компактной историей.
- Экран «Диагностика» переработан в Material 3 структуру с раскрываемыми группами сайтов, отдельным мониторингом состояния и раскрываемой технической статистикой.
- Техническая диагностика статистики скрыта за progressive disclosure, но все диагностические данные сохранены.
- Статусы `WhitelistState`, ошибки сайтов и часть сообщений Telegram/Public Service отображаются через локализованные строки.
- `README.md` восстановлен как русская UTF-8 версия и синхронизирован с `README_EN.md`.

### Исправлено

- Исправлен краш при запуске после подмены локализованного Compose `LocalContext`: `ActivityResultRegistryOwner` теперь явно сохраняется в composition locals.
- В диагностике больше не выводятся внутренние `SiteCheckErrorType.name` как пользовательский текст.

### Безопасность

- Экспорт статистики остаётся локальным и не отправляет данные в Telegram, Cloudflare Worker, public service или аналитику.
- В export не включаются Telegram secrets, `chat_id`, device tokens, auth headers, SIM/IMEI/IMSI, Wi-Fi SSID/BSSID, координаты и внутренние ID.
- TLS/hostname verification, network routing, DNS routing, classifier, persistence и public-service business logic не менялись.

## Установка и обновление

### Новая установка

1. Скачайте `WhiteListChecker-v0.10.4-release.apk` из GitHub Release.
2. Установите APK на Android 8.0+.
3. Откройте приложение и выполните ручную проверку мобильной сети.

### Обновление

Если подпись установленной версии совпадает с подписью APK, его можно установить поверх текущей версии:

```powershell
adb install -r -d WhiteListChecker-v0.10.4-release.apk
```

Флаг `-r` сохраняет данные приложения. Удаление приложения перед установкой не требуется и удалит локальные данные.

## Известные проблемы

- Релиз опубликован как beta/prerelease. Production keystore не хранится в репозитории; для сборки используется локальный release keystore.
- Классификация основана на наблюдаемых сетевых результатах и может давать ложные срабатывания.
- Raw DNS/53 не шифруется.
- Custom DNS не гарантирует обход произвольного VPN.
- WorkManager не гарантирует точное время запуска фоновой проверки.
- Android может ограничить или остановить foreground service при жёстком энергосбережении.
- Полный ручной сценарий проверки всех экранов после установки не выполнялся перед публикацией.
