# WhiteListChecker v0.7.0 MVP

Первый публичный MVP/beta-релиз WhiteListChecker.

## Что умеет

- Проверяет именно мобильную сеть, даже если активная сеть телефона — Wi-Fi.
- Использует группы FOREIGN / LOCAL сайтов.
- Определяет признаки:
  - белые списки не обнаружены;
  - похоже на включённые белые списки;
  - мобильного интернета нет;
  - проблема DNS в мобильной сети;
  - частичная проблема сети;
  - мобильная сеть недоступна.
- Подтверждает смену состояния через 2 проверки подряд.
- Отправляет локальные уведомления только при подтверждённой смене статуса.
- Отправляет Telegram-уведомления через пользовательский Cloudflare Worker relay.
- Поддерживает несколько Telegram-получателей.
- Сохраняет неотправленные Telegram-сообщения в очередь.
- Поддерживает автопроверку через WorkManager.
- Позволяет редактировать сайты проверки.
- Показывает диагностику последней проверки.

## Telegram

WhiteListChecker не хранит `BOT_TOKEN` в Android.

Для Telegram-уведомлений пользователь сам создаёт:

1. Telegram-бота через BotFather.
2. Cloudflare Worker.
3. Worker secrets:
   - `BOT_TOKEN`
   - `RELAY_SECRET`

В приложении вводятся:

- Worker URL;
- Relay Secret;
- Telegram-получатели / chat_id.

Инструкция: [docs/cloudflare-worker/README.md](../cloudflare-worker/README.md).

## Ограничения MVP

- Возможны ложные срабатывания.
- Приложение определяет симптомы сетевого режима, а не внутренние правила оператора.
- Фоновые проверки зависят от ограничений Android, прошивки и режима энергосбережения.
- Telegram требует ручной настройки собственного бота и Worker.
- Приложение не является VPN, proxy-клиентом или средством обхода блокировок.
- WorkManager не гарантирует запуск ровно по таймеру.

## Безопасность

Не публикуйте:

- `BOT_TOKEN`;
- `RELAY_SECRET`;
- `local.properties`;
- release keystore;
- логи с секретами.

## Ручная установка APK

1. Скачайте APK из GitHub Releases.
2. Установите APK на Android-устройство.
3. Разрешите установку из неизвестных источников, если Android попросит.
4. Откройте приложение.
5. Выполните ручную проверку мобильной сети.

**Примечание:** для этого MVP-релиза приложен **debug APK** для тестирования. Release signing не настроен.
