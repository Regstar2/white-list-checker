## About this release

`v0.10.4` is a beta/prerelease for the WhiteListChecker Android app. It updates the Statistics and Diagnostics screens, adds local statistics export, fixes app-language switching, and refreshes the public README files with screenshots.

No user-data migration is required. The published APK is built from the `release` variant.

## Highlights

- The Statistics screen is more compact and can export local data as `CSV`, `JSON`, or `TXT`.
- The Diagnostics screen now prioritizes the main result, summary, and problematic sites instead of showing a long technical report first.
- Selecting `English` in settings now actually switches the app UI.
- Russian and English README files are synchronized and include screenshots.
- A startup crash caused by the localized Compose `LocalContext` has been fixed.

## Changes

### Added

- Local statistics export through Android Storage Access Framework without storage permissions.
- Export formats `CSV`, `JSON`, and `TXT` for the selected period or the full locally loaded history.
- Full English translation for the main application screens.
- `Скриншоты` / `Screenshots` section in README; images are stored under `docs/assets/screenshots/`.
- Full release notes for `v0.10.4` in Russian and English.

### Changed

- The Statistics screen was rebuilt as a `whitelist-first` dashboard with the main binary status, freshness row, key metrics, and compact history.
- The Diagnostics screen was rebuilt as a Material 3 layout with expandable site groups, separate state monitoring, and expandable technical statistics.
- Technical statistics diagnostics are hidden behind progressive disclosure while keeping all diagnostic data available.
- `WhitelistState` labels, site errors, and selected Telegram/Public Service messages now use localized strings.
- `README.md` was restored as a Russian UTF-8 document and synchronized with `README_EN.md`.

### Fixed

- Fixed a startup crash after replacing the localized Compose `LocalContext`: `ActivityResultRegistryOwner` is now explicitly preserved in composition locals.
- Diagnostics no longer shows internal `SiteCheckErrorType.name` values as user-facing text.

### Security

- Statistics export remains local and does not send data to Telegram, Cloudflare Worker, public service, or analytics.
- Export does not include Telegram secrets, `chat_id`, device tokens, auth headers, SIM/IMEI/IMSI, Wi-Fi SSID/BSSID, coordinates, or internal IDs.
- TLS/hostname verification, network routing, DNS routing, classifier, persistence, and public-service business logic were not changed.

## Installation and updating

### New installation

1. Download `WhiteListChecker-v0.10.4-release-unsigned.apk` from the GitHub Release.
2. Install the APK on Android 8.0+.
3. Open the app and run a manual mobile-network check.

### Updating

If the installed app signature matches the APK signature, install it over the current app:

```powershell
adb install -r -d WhiteListChecker-v0.10.4-release-unsigned.apk
```

The `-r` flag keeps app data. Uninstalling before installation is not required and will remove local data.

## Known issues

- This release is published as a beta/prerelease and contains an unsigned `release` APK. The production keystore is not stored in the repository.
- Classification is based on observed network results and may produce false positives.
- Raw DNS/53 is unencrypted.
- Custom DNS does not guarantee bypass of an arbitrary VPN.
- WorkManager does not guarantee exact background-check timing.
- Android may restrict or stop the foreground service under aggressive battery management.
- The full manual scenario across all screens was not run before publication.
