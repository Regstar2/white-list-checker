# Добровольная отправка данных в общий сервис

## По умолчанию

Отправка данных выключена. Удалённые проверки выключены. Серверная регистрация не создаётся, пока пользователь явно не включает функцию общего сервиса или не создаёт link code.

## Что отправляется при `shareReports=true`

Только успешные результаты проверок:

- версия приложения;
- выбранный или подтверждённый пользователем регион;
- необязательный город как стабильный `cityCode` или безопасно очищенное ручное название;
- выбранный или автоматически определённый оператор;
- источник выбора региона/города и оператора;
- время проверки;
- trigger проверки;
- итоговое состояние;
- количество доступных FOREIGN/LOCAL целей;
- безопасные target codes без query;
- bucket задержки вместо точной диагностики.

## Что не отправляется

- номер телефона;
- IMEI;
- IMSI;
- точные координаты;
- raw address, улица и почтовый индекс;
- точный IP как публичное поле;
- cell ID;
- device token;
- token hash;
- Relay Secret;
- `BOT_TOKEN`;
- личные Telegram-сообщения;
- локальные файлы;
- raw logs;
- chat ID в публичную статистику.

Автоопределение местоположения запускается только после явного нажатия пользователя и использует `ACCESS_COARSE_LOCATION`. Координаты нужны только в памяти для reverse geocoding и не попадают в persistence, public report DTO, логи или D1.

Оператор определяется по active/default data subscription через платформенный `TelephonyManager`. Приложение не запрашивает номер телефона и не читает IMEI, IMSI или SIM serial.

## Device token

Android хранит token через Android Keystore-backed encryption. Worker хранит только HMAC/SHA-256 hash с `DEVICE_TOKEN_PEPPER`.

## Отзыв согласия

При выключении `shareReports` Android:

- прекращает создание новых public reports;
- очищает pending public queue безопасным значением по умолчанию;
- не отправляет уже накопленные reports без повторной проверки согласия.

Удаление серверных данных установки отзывает registration, links и active commands.

## Ограничения доверия

Данные публичного статуса предоставляются пользователями приложения и не являются официальным статусом оператора. Без device attestation защита от Sybil-атак ограничена, поэтому MVP использует privacy threshold, cooldown и правило «один последний report на installation».
